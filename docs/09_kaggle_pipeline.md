# Kaggle + Hugging Face experiment pipeline (Q1 protocol)

Entry point: `kaggle/davidnet_q1_pipeline.ipynb` (generated by `kaggle/build_notebook.py`).
Code: `src/pipeline/`. Tests: `tests/test_pipeline_units.py`, `tests/test_pipeline_recovery.py`.

## 1. Runbook

1. Kaggle notebook: GPU on, Internet on, attach the 7 datasets (listed in the notebook's first cell),
   add the `HF_TOKEN` secret (write token of the account that owns `project.hf_repo`), set a
   unique `session.worker_name` per Kaggle account.
2. `MODE = "recovery_test"` → Save & Run All (Commit). Must print `RECOVERY TEST PASSED`.
3. `MODE = "smoke"` → tiny real-data run (48 clips per split, 2 epochs, own HF namespace `smoke/`).
4. `MODE = "full"` → commit; re-commit whenever a session ends until the registry shows every
   experiment `completed`. Several accounts can run at once (claims + leases).
5. Pin `project.code_revision` to a commit hash before the runs whose numbers go in the paper.

## 2. Methodological decisions (approved 2026-09-26)

| Decision | Choice | Why |
|---|---|---|
| FakeAVCeleb split | **strict identity-disjoint** (all identities in a clip path, incl. target ids in fake filenames), stratified by race × gender, fractions 65/15/20, straddling clips dropped | the published source-only split shares identities between train and test for 100% of test clips when target ids are counted (71% vs. train folder ids) |
| Legacy split | supplementary table only (`davidnet-legacy`) | literature comparability |
| Compute | Phase A frozen VideoMAE/WavLM features for all ablations × 3 seeds; Phase B partial fine-tune for the final model × 3 seeds | full ablation matrix with seeds fits the Kaggle quota |
| Other corpora | zero-shot test-only | clean generalization claim |
| Preprocessing | identical face-centred crop (YuNet, box 1.8×) for every corpus | cross-dataset shift must not come from framing |
| Thresholds | fitted on validation (EER point), frozen for test + cross-dataset | no test-set tuning |
| Model selection | best `val/mean_auc` (video + audio AUC) | pre-registered |
| Test set | evaluated once per experiment, on the best-on-validation checkpoint | no repeated test use |
| Audio LOGO | not run | FakeAVCeleb has a single audio synthesizer (RTVC) in RVFA and FVFA |
| DeepfakeTIMIT / WaveFake | detection rate only | the mirrors contain fakes only (AUC undefined) |
| DFDC | clip + video metrics only; audio label unknown | DFDC does not label which fakes swapped audio |
| Statistics | mean ± std, Student-t 95% CI over seeds; stratified bootstrap CI per run; DeLong vs. proposed model with Holm correction | |

## 4. Fault tolerance

- Checkpoint + `LATEST.json` pointer + pruning of old checkpoints in **one** commit; sha256 /
  git-blob verification after every commit; the previous verified checkpoint is always kept.
- Resume = newest checkpoint (HF or local) that passes sha256 and config-hash checks; restores
  model, optimizer, scheduler, AMP scaler, RNG streams, loop position within the epoch, history.
  `tests/test_pipeline_recovery.py` proves kill-and-resume is bitwise identical on CPU.
- OOM → halve micro-batch, double accumulation (effective batch unchanged). Non-finite loss →
  skip; abort after 20 in a row. Session budget → checkpoint + pause before the 12 h wall.
- Uploads run in a background thread and never kill training; failures are retried at the next
  checkpoint and at the end (`flush`). HTTP 429 honours `Retry-After`.
- **Commit budget:** HF allows ~128 commits/hour/repo. Checkpoints are interval-driven
  (`every_steps` / `every_minutes`), never per epoch; one Phase-A experiment costs ~5 commits.
- A different config under an existing experiment name is refused (never overwritten).
